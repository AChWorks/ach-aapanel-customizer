What do these PHP-FPM settings mean?
pm.max_children
Maximum simultaneous PHP workers. Higher values may consume more memory.
pm.start_servers
Workers started when the service launches in dynamic mode.
pm.min_spare_servers / pm.max_spare_servers
Desired range of idle workers in dynamic mode.
pm.max_requests
Requests handled by a worker before recycling. Zero disables request-count recycling.

These are shared-pool settings, not per-website limits. Preview compares file/default values; it does not show actual worker memory usage.
